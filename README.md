# Jike Peptide website

English inquiry website for Jike Biotech (Guangzhou) Co., Ltd.

## Local development

```bash
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
```

The static export is written to `out/`.

## Form delivery

Quotation submissions are sent through the existing Formspree endpoint configured in `lib/site.ts`.
